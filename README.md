# Универсальный калькулятор для сообществ ВК

Минимально рабочая версия VK Mini App для создания и запуска калькуляторов внутри сообщества ВК.

## Стек

- React
- TypeScript
- Vite
- VKUI
- `@vkontakte/vk-bridge`
- `localStorage` для шаблонов и заявок

## Структура

- `src/pages`
- `src/components`
- `src/entities/calculator`
- `src/shared/storage`
- `src/shared/types`

## Что умеет MVP

- выбор типа калькулятора;
- конструктор шаблона для администратора;
- пользовательский ввод параметров;
- расчет итоговой стоимости;
- отправка заявки с именем, телефоном, комментарием и суммой;

## Переменные окружения

- `VK_APP_SECRET` или `VK_MINI_APP_SECRET` — нужен серверу для проверки подписи `vk_...` launch params перед доступом к защищённым API.
- `PUBLIC_APP_URL` — рекомендуется для корректного `return_url` в YooKassa без доверия к прокси-заголовкам.
- `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` — для серверного хранения настроек, шаблонов, тикетов и платежей.

## Beget: проверка VK-секрета

Если проект развёрнут на Beget, проверяйте серверные переменные именно там, а не в Vercel.

1. Откройте настройки Node.js-приложения или серверный `.env` на Beget.
2. Оставьте один корректный секрет мини-приложения VK:
   - `VK_APP_SECRET`
   - или `VK_MINI_APP_SECRET`
   - или `VK_CLIENT_SECRET`
3. Не смешивайте его с `VK_GROUP_TOKEN` или `VK_CALLBACK_SECRET`: это другие ключи и для проверки `launch params` не подходят.
4. Если заданы сразу несколько переменных с разными значениями, выровняйте их или оставьте только одну.
5. После изменения переменных обязательно перезапустите Node.js-приложение на Beget.

Короткая проверка после перезапуска:

1. Откройте мини-приложение из сообщества VK, а не по прямой ссылке.
2. Перейдите на экран ручной выдачи тарифа.
3. Если ошибка `invalid_signature` осталась, значит на сервере всё ещё используется неверный секрет или процесс не был перезапущен.

## Сборка

```bash
npm run build
```

## Подключение к VK Mini Apps

1. Создайте приложение в кабинете VK Mini Apps.
2. Укажите URL, по которому будет доступна production-сборка.
3. Настройте `App ID` и права приложения по требованиям вашего сценария.
4. При необходимости добавьте серверный слой для реальной отправки заявок в сообщения сообщества.

## Что нужно для публикации в сообществе

1. Собрать production-версию приложения.
2. Разместить сборку на HTTPS-хостинге.
3. Подключить приложение к сообществу через настройки VK.
4. Проверить сценарий открытия мини-приложения из сообщества.
5. Подготовить backend, если заявки должны автоматически уходить в CRM или сообщения сообщества.
